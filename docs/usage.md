# 使用与参数调整

## 画布结构

模型加载 → 前三种模式的8步LoRA → 前馈及注意力分块 → 显存预留与采样偏移 → 提示词与图片条件 → 采样 → 音视频潜变量拆分 → 解码 → 保存。

六个分区分别负责模型与显存、内容与参考、采样、解码、有声输出、无声输出。日常先修改绿色内容区。

## 四种模式

### 文生视频

修改主体、环境、景别、动作、光线及声音。保留 `integrated_multimodal_description`、`overall_soundscape`、`non_diegetic_music` 三段顺序。默认提示词为约5秒的人物近景表演。

### 单首帧

在 LoadImage 上传自己的图片。图片决定开始画面，提示词描述后续运动。保留开头的0.00秒首帧对齐说明，`Picture 1` 对应所选图片。默认舞蹈描述需要与自己的图片内容一起修改。

### 首尾帧

分别上传首帧和尾帧。`Picture 1` 对应开始，`Picture 2` 对应结束。默认结束时间为5.17秒，修改帧数后同步更新尾帧时间及正文动作过程。两张图的主体、服装和场景连续性会影响生成。

### 多参考

上传人物参考与环境参考，分别对应 `Picture 1` 和 `Picture 2`。按顺序保留 `subject_definitions`、`summary`、`retention_analysis`、`detailed_description`、`overall_soundscape`、`non_diegetic_music` 六段，明确每张图片提供的特征。该模式使用 REF2VA 主模型。实测第二张环境参考的遵循有限，应检查实际画面。

参考模式首次导入时，未上传图片的入口会显示“图像不存在”或图片加载提示。上传自己的图片后再运行。

## 有声与无声

默认有声 SaveVideo 启用，无声 SaveVideo 禁用。选中对应保存节点，按 Ctrl+M 切换。两个保存节点同时启用时，共用一次采样输出两份同画面视频。

无声分支省去音频解码与封装，采样仍采用音视频联合潜变量，主要采样耗时接近。日常输出位于自己的 `ComfyUI/output/H3_video`，按 t2v、i2v、fl2v、ref2v 及 audio、silent 分类。

## 参数

| 参数 | 默认值 | 调整说明 |
|---|---|---|
| width、height | 1344、768 | 当前原生画质基线 |
| length | 124 | 实际5.167秒，243帧为10.125秒 |
| fps | 24 | 两个 CreateVideo 均保持24 |
| steps | 前三种8，多参考20 | 与对应主模型及LoRA配套 |
| sampler_name | 前三种euler，多参考res_multistep | 与当前调度配套 |
| scheduler | simple | 当前已验证调度 |
| denoise | 1.0 | 四种模式的完整采样 |
| noise_seed | 20261107，fixed | 固定用于对照，改变用于探索不同结果 |
| shift_video、shift_audio | 前三种6、3，多参考12、3 | 音视频噪声调度偏移 |
| strength_model | 前三种1.0 | 768p 8步Turbo LoRA强度 |
| chunks | 4 | 前馈分块数，影响峰值激活占用和开销 |
| head_chunks | 4 | 注意力头分组数，影响峰值显存和开销 |
| memory_usage_factor | 0.2 | 采样激活显存估算系数，影响权重驻留 |
| seq_threshold | 4096 | 前馈分块启用阈值 |

当前使用17n+5的帧数网格，124和243已验证。更长帧数及其他尺寸需另测。提高分辨率、增加时长或增加步数都会改变成本，长序列开销增长明显。

### 延长到约10秒

将 length 改为243，前馈 chunks 与 head_chunks 均改为16，memory_usage_factor 保持0.2。同步修改提示词中的持续时间、动作时间及尾帧时刻。历史20步文生10秒完整实测约59分钟，当前8步配置的10秒耗时待测。

### 日常调节顺序

1. 先沿用124帧及各入口默认步数，前三种模式8步，多参考20步。
2. 用固定种子对比提示词或参考素材，每次改变一个因素。
3. 需要不同构图、动作表现时再更换种子。
4. 确认镜头内容后，再延长时长或组合多个镜头。

### 中文对白

四种模式统一使用32B编码器。将说话者、中文原话、语气与发生时间写入主体描述，保留对白原文。参考模式还需保持图像标签一致。每条对白均需试听，当前发布样例以环境声为主。
